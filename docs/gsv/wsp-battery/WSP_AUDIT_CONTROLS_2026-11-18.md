## 2. Знахідка: shared-prefix artifact

Усі чотири провальні факти **мають однаковий префікс** «Хто написав «» і **всі дають delta_rms_max = 0.4538** (до 4 знаків).
math-1 ≈ math-2 (однаковий префікс «Скільки буде…», обидва 0.3607) — той самий клас ефекту.
Висновок: **0.4538 не є сигналом фактичності** — це максимум, що припадає на спільну префіксну позицію
(token ««» / загальний префікс-interest), а не на специфіку «Пушкін vs Київ».

Попереднє формулювання з `WSP_AUDIT_RUNS_2026-11-18.md` («uk-fact-2 L23 = 0.4538 — кандидат на Astra-стиль
hypothesis») **відкликано**: matched-difficulty controls зламали інтерпретацію «шар-23 = канал фактологічної помилки».

**Вердикт по моделі:** широкий ability-gap (UA-факткола + math-baseline + codegen усе на нулі),
а не obstacle-gap з одним виміром. За Gemma-законом Astra («може зняти перешкоду, але не додати
вміння») — **WSP-патч на MiniCPM-1B зараз не має робочої гіпотези**. Попередні 2 Inkling-guided
триали (ROLLED BACK) узгоджуються з цим висновком.

## 4. Що це змінює в плані

1. **Не патчити MiniCPM-1B.** Вишуканість «layer-23 single direction» — артефакт дизайну battery;
   battery потребує **prefix-controlled** probes (той самий факт у різних синтаксах; різні факти
   у однаковому синтаксисі; різні довжини префікса) перед будь-якими редакторськими budget.
2. **Astra-like «single-direction» кандидат на 35B-A3B фактично не має точки входу без
   ActivationAudit на сам 35B** (де є справжні MoE-шари і де патчи дозволені тільки для FFN expert
   блоків, ніколи router) — але це фаза A (audit без патчів), owner-gate.
3. **Найдешевший надійний виграш для кластеру:** Uk-golden battery з owner'ом (5 фікстур) →
   baseline токен-limited behaviours на **35B-A3B** (serve через Rust FFI неможливий — тільки Pi/phones
   dispatch `weights_matvec`), або **Granite-A800M** (llama.cpp на CPU, готовий) — але жоден патч
   не призначений, поки Gemma-аналогію не пройдено (owner-gated).
4. **Inkling-only режим:** я не використовую Zen free-моделі без окремого owner-апруву; усі
   діагностики — локальні/read-only.
